# DEFINITION OF DONE

Definición del concepto *"DONE"*:

- Todos las entregas deben ser totalmente funcionales, que se puedan probar
y no se bloquee por ningún tipo de error.
- Manejar los errores o excepciones para que no haya cierres o bloqueos inesperados.
- Toda funcionalidad desarrollada debe estar mínimamente documentada, con
características, configuración y demás elementos que permitan identificarla y entenderla.
- Cada funcionalidad debe cumplir con los criterios de aceptación previamente definidos.
- Cada entrega debe funcionar de manera independiente.
- Las funcionalidades deben pasar todas las pruebas unitarias que se le hagan.
- Debe existir persistencia de datos, registrados en bases de datos, no se pueden perder registros.
